# 研究资料索引

证书、解密日志和反编译数据库均不在仓库中，因为它们可能包含用户设备标识、
测试者的网络拓扑、账号数据或第三方受版权保护的内容。

## 证据标签

- **APK 静态确认**：能够在旧 App 的构造器、解析器或实际 UI 调用链中直接
  找到，不代表对应零售型号或全部固件已经过真机验证。
- **抓包确认**：可在合法控制的实机网络流量中观察到字段或状态变化。
- **动作确认**：发送单一可逆命令后，设备物理状态和校验通过的响应同时变化。
- **推断**：现象与代码一致但缺少官方枚举或全部硬件样本，报告会明确标注，
  不把推断写成厂家定义。

## 脱敏规则

- 不发布完整设备 MAC、家庭内网 IP、HA token、Wi-Fi SSID/密码、账号、位置、
  原始广播包或设备云明文。
- 帧示例只保留协议常量和动作相关字节；设备 MAC、地址和序列号使用
  `<DEVICE_MAC>`、`<DEVICE_IP>`、`<SEQ>` 等占位符。
- 时间线改用相对时间，避免公开用户的真实作息和抓包时间。
- 不发布 APK、反编译源码或原始 pcap；样本只记录版本、包名和摘要，便于
  合法持有同一版本的研究者核对。
- 公网域名、端口、公开厂商 OUI 和公开证书元数据不是用户唯一标识，可在确有
  技术价值时保留。

## 复核原则

公开报告中的实现结论还要与当前编解码器交叉检查。若 APK 与实机结果冲突，
已验证型号优先采用实机结果；其他同协议族型号仍保持“实验性”，不能直接外推。
欢迎提交不含原始身份信息的字段变化、相对时间和型号/固件版本结果。
